Reference · Git for Vibe Coding The checkpoint loop

The compressed version of Lesson 1. Pin it. Print it. It’s the whole safety model of vibe coding on one page.

1The loop (30 seconds, repeated)

1

Start clean

git status → commit anything in flight. Never let the agent start from a dirty tree.

2

Agent works

Prompt. Walk away. It edits whatever it likes.

3

Diff gate

git diff --stat (map) → git diff <file> (details). Nothing commits unread.

4

Keep or roll back

Good → git add -A && git commit -m "…" · Bad → git restore . → tighter prompt → step 1.

2Undo table

SituationCommandTouches
One file’s uncommitted changes are badgit restore <file>that file → back to the index (usually = last commit)
All uncommitted changes are badgit restore .every modified file. Your 30-second full rollback
Staged by accidentgit restore --staged <file>index only; file content untouched
Explicit “back to the last commit”git restore --source=HEAD -- <file>file ← HEAD, even if the index differs
Bad commit, not pushedgit reset --hard <commit>tree + index + branch pointer. Local-only. Nuclear
Bad commit, pushed / sharedgit revert <commit>adds an undo-commit; history intact; safe for others
Find the checkpoint / compare to itgit log --oneline · git diff HEAD~2—

Old git (< 2.23)? git checkout -- <file> is the pre-restore spelling of row one.

3Diff red flags (stop and read the whole diff)

FlagSmells like
Deletions ≫ additionsRipped things out to make its change fit
Touched .env, config, lockfiles, deps you didn’t ask aboutScope creep — or a secret leak
Deleted red lines that were guards / error checksRemoved the guardrail to make a bug vanish
One-line ask → 20-file “refactor”Trust-but-verify failed; full read or rollback

4Guardrails for the agent itself

Ask your agent tool to confirm before: committing, force-pushing, reset --hard, deleting branches, or touching shared history. Good tools do this by default — verify yours does. AI commits can be great commit messages; the human keeps the trigger. (InventiveHQ’s AI+git guardrails)
