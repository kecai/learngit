Reference · Git for Vibe Coding The branch sandbox

The compressed version of Lesson 2. One page: the rules, the commands, the gate. Pin it next to the checkpoint loop sheet.

1The three rules

Sandbox rules main = the only work you chose to keep. The agent never builds on it.
A branch = a draft — a cheap pointer, not a copy of code.
Every branch has two exits: merged or deleted. “Keep it just in case” is branch limbo — the graveyard.

2The commands

You want to…Type…
start a draftgit switch -c <name> (old spelling: checkout -b)
go back to the safe linegit switch main
see everything a branch didgit diff main...<name> --stat (three dots = branch vs. where it left main)
keep the branchgit merge --no-ff <name> then git branch -d <name>
kill the branchgit switch main && git branch -D <name>
back up a long experimentgit push -u origin <name> (not a “keep” decision)

-d lowercase refuses to delete unmerged work. -D uppercase means “I mean it.”

3The merge-or-kill gate

1

Does it work?

Run the app / the tests. Current state, not memory.

2

Does the diff match the ask?

git diff main...<name> against your prompt’s words. Red flags apply at branch scale.

3

Can you explain it in one sentence?

If not, you’re not merging it.

All yes → merge (--no-ff, then -d). Any no → kill (-D, re-ask tighter). “The agent spent 45 minutes on it” is a sunk cost, not a reason. The work is a draft, not an asset. Exception: hand-pick surgery only when the kept part is costly to re-derive.

4Guardrails (set once, forget)

• Name the branch in the prompt: “Work on branch x, don’t touch main.” · • Forbid: auto-merge to main, auto-push to main, force-push. · • Allow auto-commits on the branch — they’re draft checkpoints. · • The agent commits; you merge and delete.

5Quick recovery

SituationMove
Branch is bad, unmergedgit switch main && git branch -D <name> — ten seconds, main was never touched
Merged a branch, then regret itgit revert -m 1 <merge-commit> — the --no-ff hump makes one command undo the whole feature
Accidentally on main when the agent startsDon’t panic — that’s Lesson 3’s problem (revert / reset). Stop the agent first.
Branch list filling upgit branch, then the gate, then delete. Two exits, no limbo.
